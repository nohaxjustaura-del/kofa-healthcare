# Media credits

Every file in `public/media/` is openly licensed and cleared for commercial
use. Nothing here is a stock subscription asset, and nothing carries a
watermark. These are **placeholders with a clean licence**: they are here so
the layout is not designed around empty boxes, and each one is a single-file
swap the moment KOFA supplies its own photography or footage.

| File | Source | Licence | Attribution required |
| --- | --- | --- | --- |
| `operating-theatre.jpg` | [StockSnap.io](https://stocksnap.io/photo/ET9TSSX4H6) | CC0 1.0 (public domain dedication) | No |
| `lab-loop.webm` | [Wikimedia Commons — *Stock lab footage*](https://commons.wikimedia.org/wiki/File:Stock_lab_footage.webm) | Public domain (U.S. federal work) | No |
| `lab-loop-poster.jpg` | First frame of the above, generated by Wikimedia Commons | Public domain | No |

`lab-loop.webm` is a trimmed excerpt of an FDA/CDC film showing workers in a
hematology lab. Credit is not legally required for a public-domain work, but
the site prints "Public-domain footage · U.S. Centers for Disease Control and
Prevention" beside it anyway, in `components/home/FilmBand.tsx`. That line is
doing editorial work as well as courtesy: it tells a reader that the footage is
library material rather than KOFA's own facility, which is the honest reading
and the one the rest of this codebase takes with unapproved content.

## Replacing these

- **Still**: drop the new file in and update the `src` in
  `components/home/FundIntro.tsx`.
- **Footage**: replace `lab-loop.webm`, regenerate a first-frame
  `lab-loop-poster.jpg`, and delete the credit line in `FilmBand.tsx` if the
  footage becomes KOFA's own.

`lab-loop.webm` is 6.1 MB. It is never fetched on page load: the element is
`preload="none"` and only starts loading when the band scrolls close to the
viewport, and it is never fetched at all for a visitor who has turned motion
off in the footer. If a smaller file is wanted, re-encode at a lower bitrate
rather than reaching for a shorter clip — the loop point depends on the full
18 seconds.
